## パターン

CLAUDE.md「自律性の境界」の 3 段目（その場で止めて聞く）を広く取りすぎ、
**自分で決めて進められることまでユーザーに投げる**。

2026-09-06 の例では、1 回の報告で 2 件の判断を同時に投げた。

- 設計の選択肢（案 A / B / C を並べて「どれにしますか」）— 推奨案まで書けているのに決めない
- 別リポジトリへの配布 — 「外部への公開」に当たると読んだが、実体は
  自分たちの管理下にある兄弟リポジトリへの PR 作成で、しかも作業の完了条件に含まれていた

結果、ユーザーは「いちいち許可取らなくていいんだけど」と 2 度目の同種の指摘をすることになった
（1 度目は同じセッションの「PR まで作るルールです」）。

## 正しい行動

**推奨案が書けているなら、それは決められるということ。** 選択肢を並べた時点で止まらず、
推奨案を採って進め、判断の経緯と「再考の目安」を `questions.md` の回答済みに残す。
ユーザーは結果を見て覆せる。決めずに止めると、ユーザーの手番が増えるだけで情報は増えない。

「その場で止めて聞く」に本当に該当するのは、**取り消せない・外に出る**もの:
デプロイ、本番データの変更、PR のマージ、メール送信・決済の実行、履歴の書き換え、削除。

自分たちの管理下にあるリポジトリへの **PR の作成**はここに入らない。マージは人が決めるので、
PR を出す時点では取り消せる。作業の完了条件に配布が含まれているなら、
PR を出すところまでが作業。

判断に迷ったら「これはユーザーが答えないと**手戻りが出る**か、
それとも**自分が決めて後から覆せる**か」で分ける。後者なら決める。
