# Mobile Assets

`app.config.ts` で参照されるアセットをここに配置する。

## 必要なファイル

| ファイル            | サイズ       | 用途                           |
| ------------------- | ------------ | ------------------------------ |
| `icon.png`          | 1024x1024    | アプリアイコン                 |
| `splash-icon.png`   | 200x200 以上 | スプラッシュ画面のアイコン     |
| `adaptive-icon.png` | 1024x1024    | Android のアダプティブアイコン |

単色のプレースホルダーを同梱している（クローン直後でも `expo start` がエラーにならないため）。
プロジェクト開始時に実際のデザインに差し替えること。
