# Mobile Assets

`app.json` で参照されるアセットをここに配置する。

## 必要なファイル

| ファイル            | サイズ       | 用途                           |
| ------------------- | ------------ | ------------------------------ |
| `icon.png`          | 1024x1024    | アプリアイコン                 |
| `splash-icon.png`   | 200x200 以上 | スプラッシュ画面のアイコン     |
| `adaptive-icon.png` | 1024x1024    | Android のアダプティブアイコン |

プレースホルダーは含まれていないので、プロジェクト開始時に作成すること。
