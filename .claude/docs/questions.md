# 確認事項キュー

> ユーザーへの確認が必要になったとき、**セッションを止めずにここへ積む**ためのファイル。
> 判断の基準と積み方は CLAUDE.md「自律性の境界」を参照。
> ユーザーはここを見て**まとめて答える**（`/questions`）。回答済みの項目は下のセクションへ移す。

積むときのルール:

- **1項目 = 1判断**。「ついでに」を混ぜない（まとめて答えられなくなる）
- **推奨案を必ず書く**。ユーザーが「それで」と一言で返せる状態にする
- **影響**に「回答が変わったとき何を直すか」を書く。ここが軽いと即答できる
- 仮決定して実装を進めた場合は、**どのファイルに入っているか**を書く
